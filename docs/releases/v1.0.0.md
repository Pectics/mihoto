# Mihoto v1.0.0

Mihoto 1.0 is the first stable release of the root-owned, systemd-only Mihomo
manager. It is the intentional compatibility boundary from the former
per-user Mihoro application.

## Highlights

- Four release artifacts for x86_64 and aarch64 GNU/musl Linux targets.
- Root-owned configuration, binaries, Mihomo state, service, and update timer.
- TUN-ready service capabilities with reboot-persistent systemd ownership.
- Staged Mihomo configuration validation before replacement.
- Service health verification that detects restart loops and atomically
  restores the previous configuration.
- Exact release asset selection, `SHA256SUMS`, staged executable smoke tests,
  atomic installer/self-upgrade replacement, and GitHub build provenance.

## Install and verify

```sh
curl -fsSL https://raw.githubusercontent.com/Pectics/mihoto/main/install.sh \
  | sudo sh -s -- --version v1.0.0
```

Verify a downloaded archive:

```sh
sha256sum --check SHA256SUMS
gh attestation verify mihoto-v1.0.0-x86_64-unknown-linux-gnu.tar.gz \
  --repo Pectics/mihoto
```

## Configuration note

Profiles exported by GUI clients may omit DNS and TUN settings injected by the
GUI at runtime. Mihoto requires a standalone Mihomo YAML configuration. For
full-host TUN, include working DNS and DNS-hijack settings as well as the node,
groups, and rules.

## Migration and removal

Mihoro installations are not migrated automatically. Plain `uninstall`
removes system units while retaining Mihoto/Mihomo state and binaries.
`uninstall --purge --yes` removes the Mihoto-managed persistent state.

## Acceptance boundary

The physical `pectos` run on Ubuntu 26.04 x86_64 verified systemd/TUN creation,
reboot restoration, updates, timer behavior, recovery, and cleanup while
exposing the configuration restart-loop defect fixed before this release.
Ubuntu 22.04, Ubuntu 24.04, and aarch64 real-host expansion remain recorded in
the stable audit rather than being represented as completed runs.
